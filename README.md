# Frase — испанский для Сергея

Android-приложение для изучения испанского с нуля: путь из ступеней с тестами,
словарь, тренажёры, чтение с переводом по тапу, озвучка, виджет и напоминания.

## Что внутри

**Путь** — 10 ступеней. Каждая открывается тестом предыдущей (15 заданий, порог 80%).
Прогресс сохраняется в телефоне.

**Фраза** — карточка-схема: слова с выносками и подписью роли, глагол выделен,
перевод спрятан. Регулятор скорости речи.

**Правила** — 10 тем: чтение, глагол обязателен, отрицание и вопрос, род,
порядок слов, артикли, три группы глаголов, инфинитивные конструкции,
числительные, карта времён.

**Глаголы** — 8 таблиц спряжения с произношением: ser, tener, estar, querer,
poder, ir, vivir, trabajar. Тап по форме — произносится.

**Практика** — четыре режима:
- Фразы: сборка предложения, три уровня сложности
- Хвосты: тренажёр окончаний со сворачиваемой таблицей-подсказкой
- Слова: 1294 слова, интервальные повторения, написание со слуха
- Чтение: 30 текстов по ступеням, тап по слову — перевод и озвучка

**Виджет** на рабочий стол и **уведомления** раз в 3 часа.

Словарь — 1553 статьи. Поиск понимает множественное число,
спрягнутые формы и слова без значков ударения.

## Сборка APK

1. Залить файлы в репозиторий GitHub, сохранив структуру папок.
2. Вкладка **Actions** → **Build APK** → **Run workflow**
   (или просто сделать коммит — сборка запустится сама).
3. Через 2–3 минуты внизу страницы сборки: **Artifacts** → **frase-apk**.
4. Распаковать zip, перекинуть `app-debug.apk` на телефон, установить.

Сборка debug, подписывается автоматически — отдельный ключ не нужен.

## Установка на телефон

Настройки → Приложения → Особый доступ → Установка неизвестных приложений →
разрешить для Chrome или «Файлы». После установки разрешение отключить обратно.

Виджет: долгое нажатие на рабочем столе → Виджеты → Frase.

## Если голос молчит

Настройки Android → Специальные возможности → Синтез речи →
скачать испанский языковой пакет.

## Правки на будущее

Весь учебный материал — слова, тексты, правила, глаголы, вопросы тестов —
лежит в одном файле `app/src/main/assets/app.html`.
Java трогать не нужно, кроме настроек озвучки в `MainActivity.java`.
