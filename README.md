# Frase — испанский виджет + напоминания

Виджет на рабочий стол и уведомления с испанской фразой и разбором грамматики.

## Как собрать APK

1. Загрузить все файлы в репозиторий GitHub (сохранив структуру папок).
2. Вкладка **Actions** → workflow **Build APK** → **Run workflow**.
3. Через 3–5 минут внизу страницы появится артефакт **frase-apk** — скачать.
4. Распаковать zip, перекинуть `app-debug.apk` на телефон, установить.

Сборка debug — подписывается автоматически, отдельный ключ не нужен.

## Установка на телефон

Настройки → Приложения → Особый доступ → Установка неизвестных приложений →
разрешить для Chrome или Файлы. После установки — отключить обратно.

## Уведомления

и восстанавливаются после перезагрузки телефона.
